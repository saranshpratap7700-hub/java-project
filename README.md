The Hospital Management System is a Java console-based application designed to manage patients, doctors, and appointments efficiently. It demonstrates Object-Oriented Programming (OOP) concepts such as classes, objects, inheritance, and collections, along with user input handling using Scanner.

This project is ideal for academic submissions and showcases practical application of Java programming.

Features:-
 
 Add new Patients with details (ID, name, age, disease).
 
 Add new Doctors with details (ID, name, specialization).
 
 Book Appointments between patients and doctors.
 
 View all Patients, Doctors, and Appointments.
 
 Interactive menu-driven console interface.

Technologies Used:-
 
Java SE (Core Java)

Collections Framework (ArrayList)

Scanner Class for user input

OOP Concepts (Encapsulation, Abstraction, Polymorphism)

Project Structure:-

Patient → Stores patient details.

Doctor → Stores doctor details.

Appointment → Links patient with doctor.

HospitalManagementSystem → Main class with menu-driven interface.
